Overview

PushPlay is a controller-first game launcher for Steam Deck, Linux, Windows and Mac. Point it at a GitHub repo, a folder, a .zip or a website and the game shows up in your library, then updates on its own whenever you push. It's built for playtests, prototypes and the games you make just for yourself, the ones that don't belong on a store.

Describe a game. Play it on your Deck.

Ask a coding agent from your phone. Your repo builds and tests it on every push, and it lands in your library ready to play.

A Look Inside

Every screen is built for a controller and the Deck's 1280×800 display, and works just as well with a keyboard.

Features

🎮

Controller First

The whole launcher runs on the d-pad, with a pause menu in every web game. Keyboard and mouse work too.

🐙

Games From GitHub

Add your own repos, public ones, or any you can access. Releases you already publish just work.

🔄

Auto-Updates

Push a change and it's waiting next time you pick it up, never mid-game, with a roll back if it misbehaves.

📦

Sideload Anything

Add a zip or folder from Downloads, an SD card or a USB drive, or play a hosted game website live.

📱

Sign In By QR Code

Connect GitHub by scanning a code with your phone. No typing on the handheld.

🕹️

Web & Native Games

Run browser games and native Godot builds side by side in the same library.

🏷️

Library Tools

Search, favorites, tags, filters and A–Z sorting keep a growing pile of prototypes manageable.

🤖

AI-Ready Template

A games repo template builds and tests every push, so a coding agent can ship a game straight to your Deck.
