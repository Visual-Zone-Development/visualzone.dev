Overview

PushPlay puts your games on every screen you play on: a Steam Deck, a Windows, Mac or Linux PC, and soon your phone and tablet. Point it at a GitHub repo, a folder, a .zip or a website and the game shows up in your library, then updates on its own whenever you push. It's built for playtests, prototypes and the games you make just for yourself, the ones that don't belong on a store.

Your library, in your pocket.

Every launcher screen is built for a controller and the Deck's 1280×800 display, and works just as well with a keyboard. The phone app brings the same library to a touchscreen.

Features

🎮

Controller First

The whole launcher runs on the d-pad, with a pause menu in every web game. Keyboard and mouse work too.

🐙

Games From GitHub

Add your own repos, public ones, or any you can access. Releases you already publish just work.

🔄

Auto-Updates

Push a change and it's waiting next time you pick it up, never mid-game, with a roll back if it misbehaves.

📦

Sideload Anything

Add a zip or folder from Downloads, an SD card or a USB drive, or play a hosted game website live.

📱

Sign In By QR Code

Connect GitHub by scanning a code with your phone. No typing on the handheld.

🕹️

Web & Native Games

Run browser games and native Godot builds side by side. A web build plays on handhelds, PCs and phones alike.

🏷️

Library Tools

Search, favorites, tags, filters and A–Z sorting keep a growing pile of prototypes manageable.

🤖

AI-Ready Template

A games repo template builds and tests every push, so a coding agent can ship a game straight to your Deck.
